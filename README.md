# Sell My Stuff

Sell My Stuff is a self-hosted AI assistant that turns photographs of unwanted possessions into researched, reviewable sale proposals and—only after explicit approval—performs and verifies the selling work.

The project is at foundation stage. The current application demonstrates the intended low-friction, multi-photo intake experience; persistence and AI research are the next vertical slice.

## Development

```sh
npm install
npm run dev
```

Quality checks:

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

Start with `BRIEF.md`, then read `PROJECT_STATUS.md`, `ROADMAP.md` and `LLM_HANDOFF.md`.
